# AgentVault documentation / 文档导航

AgentVault provides policy-controlled outbound payments and evidence-based inbound settlement through HTTP SDKs.

AgentVault 通过 HTTP SDK，提供受策略约束的付款和以可信结算证据为依据的收款能力。
